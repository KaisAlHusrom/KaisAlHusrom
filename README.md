### Featured project

<img src="assets/bishola-logo.png" alt="Bishola logo" width="96" align="left"/>

**Bishola (بسهولة)**  
A marketplace for buying, selling and renting cars in Syria, live on iOS and Android.  
I built and maintain the backend, the admin dashboard and the mobile app, and I run the production servers.

<br clear="left"/>

The backend is a NestJS API, and the app is React Native. I rebuilt the app from scratch to replace the original Expo version, and deployments run on Docker and Nginx through GitHub Actions.

A few things that went into it:

- Full Arabic and English support with proper right-to-left layouts
- Push notifications with deep links that open the right screen, even when the app is closed
- Nibras, an AI assistant that helps people find the right car
- Installment plans, saved-search alerts, and profiles for sellers and dealerships
